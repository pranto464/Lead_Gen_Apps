1. Cloudflare D1

  1. Cloudflare Dashboard → D1 → Create database → নাম lead-research-desk।
  2. Account ID এবং Database ID copy করুন।
  3. API Tokens → Custom token → Account / D1 / Edit permission দিন। Token secret রাখুন।

2. Google login ও Sheets

  1. Google Cloud Console-এ project বানিয়ে Google Sheets API enable করুন।
  2. OAuth consent screen বানান। Private pilot হলে External + Testing এবং owner/worker-দের Test users-এ যোগ করুন।
  3. Web OAuth client বানান। Authorized origin: https://your-site.netlify.app।
  4. Redirect URI: https://your-site.netlify.app/api/google। Custom domain ব্যবহার করলে সেটিও যোগ করুন।

3. Netlify deploy

  1. ZIP extract করে private GitHub repository-তে source upload করুন। .env বা secret upload করবেন না।
  2. Netlify → Add new project → Import existing project → repository select।
  3. Build command pnpm build:netlify, Publish out, Functions netlify/functions।
  4. নিচের environment variables দিন, তারপর deploy করুন।
CLOUDFLARE_ACCOUNT_ID
Cloudflare Account ID
CLOUDFLARE_D1_DATABASE_ID
D1 Database ID
CLOUDFLARE_API_TOKEN
D1 Edit token
AUTH_SECRET
32+ character random secret
OWNER_SETUP_KEY
আলাদা 32+ character one-time secret
GOOGLE_CLIENT_ID / GOOGLE_CLIENT_SECRET
Google OAuth web client
FIRECRAWL_API_KEY
Web search ও public page reading
OPENAI_API_KEY / OPENAI_MODEL
GPT automatic tools
ANTHROPIC_API_KEY / ANTHROPIC_MODEL
Claude automatic tools

শুধু out folder Netlify Drop-এ upload করলে backend চলবে না। GitHub import ব্যবহার করুন।

4. Owner setup

  1. Deployed link খুলুন → First-time owner setup।
  2. Name, email, 12+ character password এবং OWNER_SETUP_KEY দিন।
  3. Owner তৈরি হলে D1 tables automatic হবে। Onboarding শেষ করুন।
  4. Owner এখন Company Research, Growth Studio এবং Admin—সব ব্যবহার করতে পারবে। পরে OWNER_SETUP_KEY remove করতে পারেন।

5. Worker signup ও approval

  1. Worker Gmail/Workspace Google button অথবা company email/password দিয়ে signup করবে।
  2. Account Pending থাকবে। Admin → Your team খুলুন।
  3. Status Active করুন এবং Product access-এ Lead Generation & Sales, Marketing & Content, অথবা দুটো checkbox দিন।
  4. Trial/Ongoing plan, days এবং AI action allowance দিয়ে Save account করুন।
  5. Worker আবার sign in করলে শুধু approved tool দেখবে। দুটো checkbox দিলে complete app পাবে।

6. গুরুত্বপূর্ণ নিয়ম

  • ChatGPT Plus ও Claude chat subscription API credit নয়। Automatic app tools-এর API billing আলাদা। Company Research-এর Manual mode-এ paid chat account copy/paste দিয়ে ব্যবহার করা যায়।
  • LinkedIn, Facebook ও job board বাদ দেওয়া হয়নি। Task/brief-এ চাইলে Firecrawl accessible public result খুঁজবে; inaccessible data বানাবে না।
  • Worker provider keys দেখতে পাবে না। Google Sheets-এর জন্য প্রত্যেকে নিজের Google account connect করবে।
  • Live commercial launch-এর আগে payment, email verification, password recovery, privacy policy, terms, monitoring এবং paid infrastructure যোগ করুন।

সমস্যা হলে

Pending: Active + অন্তত একটি product checkbox। Google blocked: OAuth Test users check। redirect mismatch: exact /api/google URI। AI unavailable: key এবং model দুটোই check। Web research fails: Firecrawl key/credit check। Allowance reached: Admin allowance বাড়াবে বা Ongoing plan দেবে।
